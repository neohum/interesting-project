붙여 넣은 트렌딩 목록 90개를 실행 조건별로 나누고, 그중 애니메이션·그림·영상을 직접 만들어 볼 수 있는 6개를 골랐다. 각 프로젝트가 만들어 내는 결과물을 그림으로 보여 주고, 주말에 해볼 만한 미니 프로젝트를 붙였다.

  • 90정리한 레포
  • 32CPU만으로 로컬 실행
  • 28AI 에이전트용 스킬
  • 6직접 해볼 추천작

CLI로 검색하고 바로 돌리기

repolab은 이 목록을 터미널에서 검색하고, 얕은 클론과 설치·실행까지 이어 주는 도구다. 의존성 없이 Node.js 18 이상과 git만 있으면 macOS·Windows·Linux에서 똑같이 돈다.

설치

# 1. 이 프로젝트 받기
git clone https://github.com/neohum/interesting-project.git
cd interesting-project

# 2. 이 폴더에서 바로
node bin/repolab.mjs help

# 3. 어디서나 repolab 으로 쓰기
npm link
repolab doctor   # git/node/cargo/python 점검

찾아보기

repolab picks                     # 추천 6선
repolab search hwp markdown       # AND 검색
repolab list --local ready --lang Rust
repolab show anatomy              # 일부 이름도 OK
repolab cats                      # 분류별 개수

클론하고 실행

repolab clone anime               # 프로젝트의 repos/ 에 --depth 1
repolab run mesh2motion-app       # 클론→설치→실행 (확인 후)
repolab run artcraft --dry-run    # 계획만 보기
repolab serve anatomy --open
repolab check --all               # 레포 존재 확인

로컬 실행 등급

    직접 해볼 만한 6선

    모두 내 컴퓨터에 GPU가 없어도 된다. ArtCraft는 생성을 클라우드 모델에 맡기고, Anatomy와 huashu-art-motion은 코딩 에이전트에 설치해 쓰는 스킬이다. 카드의 그림은 각 프로젝트를 돌리면 얻는 결과물을 그린 예시이고, 맨 아래 명령 한 줄이면 클론부터 실행까지 이어진다.

    01 juliangarnier/anime 로컬OK JavaScript · ★ 74k

    anime.js

    타임라인으로 짜는 웹 애니메이션 엔진

    CSS·SVG·DOM 속성·JS 객체를 같은 API로 움직인다. 예제 폴더가 풍부해서 클론 후 바로 수십 개 데모를 브라우저로 볼 수 있다.

    얻는 결과물

    • examples/ 폴더의 인터랙티브 데모 모음
    • 직접 만든 키네틱 타이포그래피·SVG 라인 드로잉
    • 스크롤 연동 애니메이션 페이지

    해볼 만한 미니 프로젝트

    • 한글 키네틱 인트로자모를 span으로 쪼개 stagger로 튀어 오르게 하는 5초짜리 오프닝. 화면 녹화하면 영상 인트로가 된다.
    • 깃 커밋 타임라인 애니메이션git log를 JSON으로 뽑아 커밋이 하나씩 쌓이는 SVG 그래프로 재생한다.

    필요: git, node설치 규모: 소

    repolab run anime

    02 Mesh2Motion/mesh2motion-app 로컬OK TypeScript · ★ 3.5k

    Mesh2Motion

    3D 모델에 뼈대를 심고 애니메이션을 입힌다

    Mixamo처럼 리깅·모션을 자동으로 붙여 주는 브라우저 앱이다. 클라우드 업로드 없이 내 컴퓨터에서 처리된다.

    얻는 결과물

    • 자동 리깅된 캐릭터
    • 걷기·달리기 같은 애니메이션 프리셋
    • GLB로 내보낸 애니메이션 모델

    해볼 만한 미니 프로젝트

    • 웹 게임 캐릭터내보낸 GLB를 Three.js 씬에 불러와 방향키로 걷게 한다.
    • 회사 마스코트 GIF간단한 마스코트 모델에 손 흔들기 모션을 입혀 화면 녹화로 GIF·이모지를 만든다.

    필요: git, node설치 규모: 소

    repolab run mesh2motion-app

    03 JohnHeibel/ClaudeAnimationBase 로컬OK JavaScript · ★ 1.3k

    Claude Animation Base

    손그림 카툰을 코드로 그리고 MP4로 뽑는다

    p5.js와 p5.brush로 붓질·수채 느낌의 카툰을 그리는 스타터 키트다. 캐릭터 Clawd와 감정 31가지, 장면 타임라인, 헤드리스 렌더러가 들어 있다. 클론하고 npm install 한 번이면 데모 영상이 나오고, 코딩 에이전트에게 ANIMATION_GUIDE.md를 읽힌 뒤 장면을 주문할 수도 있다.

    얻는 결과물

    • out/sheet.jpg — 1초 간격 6컷 콘티 시트
    • out/video.mp4 — 11초짜리 데모 애니메이션
    • studio.html — 브라우저에서 프레임을 넘겨 보는 스튜디오

    해볼 만한 미니 프로젝트

    • 15초 생일 카드 영상Clawd가 케이크 촛불을 불어 끄는 장면을 src/scenes/에 짜고 render.mjs로 MP4를 뽑아 메신저로 보낸다.
    • 우리 팀 마스코트 감정 시트캐릭터 모양만 바꿔 감정 31가지를 다시 그리고 ?loop=emotions 화면을 녹화해 이모지 GIF 세트를 만든다.

    필요: git, node, Google Chrome, ffmpeg설치 규모: 소 (npm 패키지 46개)

    repolab run ClaudeAnimationBase

    04 storytold/artcraft 무거움 Rust · ★ 34k

    ArtCraft

    장면을 먼저 짜고 생성하는 AI 이미지·영상 IDE

    2D 레이어 합성, 3D 장면 배치, 캐릭터 포즈, 카메라 위치를 먼저 잡은 뒤 이미지·영상 모델로 생성하는 데스크톱 앱(Rust·Tauri)이다. 생성은 클라우드 모델이 하므로 내 컴퓨터에 GPU가 필요 없다. 대신 생성에는 계정이 필요하고, 소스 빌드는 무겁다. 빌드 없이 쓰려면 공식 사이트의 Windows·macOS 설치본을 받는다.

    얻는 결과물

    • 직접 빌드한 ArtCraft 데스크톱 앱 (개발 모드)
    • 3D 장면·포즈·카메라를 고정해 뽑은 일관된 컷
    • 이미지 → 영상, 이미지 → 3D 메시 결과물

    해볼 만한 미니 프로젝트

    • 4컷 스토리보드같은 방(Image to Location)에 인물을 세우고 카메라만 옮겨 4컷을 뽑아, 짧은 영상 콘티로 쓴다.
    • 상품 소품 컷상품 사진의 배경을 지우고 3D 장면에 올려 각도·조명이 다른 홍보 이미지를 여러 장 만든다.

    필요: git, node 20+, cargo (Rust), tauri-cli 2설치 규모: 대 (Rust 빌드 수 GB, 첫 빌드 수십 분)

    repolab run artcraft

    05 wheresryan22/anatomy 스킬 JavaScript · ★ 17k

    Anatomy

    개념을 움직이는 아이소메트릭 기계 그림으로 설명한다

    "캐시 키"를 핀 텀블러 자물쇠로 바꾸듯, 기술 개념을 실제로 작동하는 물건으로 바꿔 수십 개 부품의 SVG·WebGL 그림으로 그려 주는 에이전트 스킬이다. 의존성이 없고 API 키도 필요 없다. 완성된 예제 페이지가 저장소에 들어 있어 클론만 해도 바로 열어 볼 수 있다.

    얻는 결과물

    • examples/의 인터랙티브 그림 9종 (로켓 엔진, 리플 탱크, 다이얼 게이지 …)
    • 마우스를 올리면 분해·작동하는 단일 HTML 그림
    • /anatomy 명령으로 직접 주문한 내 개념도

    해볼 만한 미니 프로젝트

    • 우리 서비스 아키텍처 기계도"요청 큐와 워커"를 컨베이어 벨트와 작업대로 그려 달라고 주문해 사내 위키 첫 화면에 붙인다.
    • 수업용 원리 그림토큰 버킷, 해시 테이블처럼 설명하기 어려운 개념을 손으로 돌려 보는 그림으로 만들어 발표 자료에 넣는다.

    필요: git, node 20.10+ (스킬 사용 시), Claude Code·Codex 등 코딩 에이전트설치 규모: 소 (의존성 0)

    repolab run anatomy

    06 alchaincyf/huashu-art-motion 스킬 JavaScript · ★ 4.6k

    huashu-art-motion

    35가지 미술 화풍으로 움직이는 그림을 코드로 렌더링한다

    동굴 벽화부터 고흐, 우키요에, 8비트까지 화풍마다 붓질·색·전환을 코드로 옮긴 레시피와 장면 코드가 들어 있는 애니메이션 스킬이다. 브라우저 캔버스로 그린 뒤 Playwright와 ffmpeg로 프레임을 뽑아 MP4를 만든다. 문서는 중국어지만 렌더러는 명령 한 줄로 돈다.

    얻는 결과물

    • 화풍별 정지 프레임 (예: 고흐 후기인상파 장면 PNG)
    • spec JSON 한 장으로 만드는 해설 애니메이션 MP4 (예: 금융 차트)
    • 배경음까지 코드로 합성한 짧은 아트 필름

    해볼 만한 미니 프로젝트

    • 우리 동네 미술사 투어같은 골목 구도를 수묵화·인상파·픽셀아트 세 화풍으로 렌더링해 전환이 이어지는 30초 영상을 만든다.
    • 월간 지표 해설 영상예제 spec의 숫자와 라벨만 바꿔 이번 달 매출 그래프가 그려지는 해설 클립을 뽑는다.

    필요: git, uv (Python), ffmpeg, Playwright Chromium설치 규모: 중 (Chromium 약 100MB)

    repolab run huashu-art-motion

    그림은 실제 스크린샷이 아니라 결과물 형태를 보여 주는 일러스트다. 그림 속 수치(속도·메모리 등)도 예시다.

    그 밖에 볼 만한 것

    준비가 조금 더 들거나 쓰임새가 좁지만 손대 볼 가치가 있는 레포.

    • dgreenheck/tidewaterWebGPU 섬 낚시 게임. 3D 품질은 최고지만 README가 성능 좋은 GPU와 WebGPU 브라우저를 요구한다.
    • edwardkim/rhwpHWP를 SVG로 내보내는 Rust CLI와 웹 에디터. WASM 빌드는 Docker를 쓴다.
    • firecrawl/anydocWord·PPT·Excel·EPUB → Markdown. Node/Python 바인딩이 있다.
    • nilbuild/page-mascot커서를 쳐다보는 마스코트를 내 블로그에 붙인다.
    • jeffhajewski/latticedb단일 파일 지식그래프 DB. Zig 툴체인으로 빌드한다.
    • naver/d2-coding-font설치만 하면 되는 개발용 한글 글꼴.
    • LibreSprite/LibreSprite픽셀 아트 에디터. 소스 빌드는 무겁고 CMake가 필요하다.
    • coollabsio/coolify남는 PC나 VPS에 개인 Vercel을 차린다. Docker가 필요하다.
    • vincentsch/explainroo로컬 TTS·Whisper로 내레이션 영상 생성. CPU로 되지만 느리고 모델이 크다.
