GPU 없이, 오늘 저녁
내 노트북에서 돌려 볼 레포

붙여 넣은 트렌딩 목록 개를 실행 조건별로 나누고, 그중 애니메이션·그림·영상을 직접 만들어 볼 수 있는 개를 골랐다. 각 프로젝트가 만들어 내는 결과물을 그림으로 보여 주고, 주말에 해볼 만한 미니 프로젝트를 붙였다.

  • 정리한 레포
  • CPU만으로 로컬 실행
  • AI 에이전트용 스킬
  • 직접 해볼 추천작

직접 해볼 만한 선

모두 내 컴퓨터에 GPU가 없어도 된다. ArtCraft는 생성을 클라우드 모델에 맡기고, Anatomy와 huashu-art-motion은 코딩 에이전트에 설치해 쓰는 스킬이다. 카드의 그림은 각 프로젝트를 돌리면 얻는 결과물을 그린 예시이고, 맨 아래 명령 한 줄이면 클론부터 실행까지 이어진다.

그림은 실제 스크린샷이 아니라 결과물 형태를 보여 주는 일러스트다. 그림 속 수치(속도·메모리 등)도 예시다.

그 밖에 볼 만한 것

준비가 조금 더 들거나 쓰임새가 좁지만 손대 볼 가치가 있는 레포.

전체 목록

로컬 실행 등급은 설명과 매니페스트를 보고 매긴 판단이다. 별·포크 수는 붙여 넣은 목록의 스냅샷이다.

레포설명언어★로컬카테고리

CLI로 검색하고 바로 돌리기

repolab은 이 목록을 터미널에서 검색하고, 얕은 클론과 설치·실행까지 이어 주는 도구다. 의존성 없이 Node.js 18 이상과 git만 있으면 macOS·Windows·Linux에서 똑같이 돈다.

설치

# 이 폴더에서 바로
node bin/repolab.mjs help

# 어디서나 repolab 으로 쓰기
npm link
repolab doctor   # git/node/cargo/python 점검

찾아보기

repolab picks                     # 추천 선
repolab search hwp markdown       # AND 검색
repolab list --local ready --lang Rust
repolab show anatomy              # 일부 이름도 OK
repolab cats                      # 분류별 개수

클론하고 실행

repolab clone anime               # ~/repolab 에 --depth 1
repolab run mesh2motion-app       # 클론→설치→실행 (확인 후)
repolab run artcraft --dry-run    # 계획만 보기
repolab serve anatomy --open
repolab check --all               # 레포 존재 확인

로컬 실행 등급

    repolab html로 다시 만든 페이지 · 데이터: data/repos.json, data/picks.json · 레포 정보는 스냅샷이므로 실행 전 각 README를 확인할 것.
